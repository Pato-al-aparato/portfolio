# Portfolio personal

Portfolio web personal orientado a presentar mis proyectos, conocimientos y evolución como desarrollador, con especial atención a la identidad visual y al diseño UX/UI.

## Estado

**En desarrollo.** El diseño y la estructura están en proceso de refinamiento antes de publicar una primera versión estable.

## Objetivos

- Presentar proyectos de forma clara y visual.
- Mantener una identidad propia sin recurrir a una estética genérica de portfolio tecnológico.
- Diseñar una navegación sencilla y una jerarquía visual cuidada.
- Adaptar correctamente la experiencia a escritorio y dispositivos móviles.
- Utilizar el proyecto como escaparate técnico y visual para procesos de prácticas y oportunidades junior.

## Tecnologías

- HTML
- CSS
- JavaScript
- Git y GitHub

## Enfoque visual

El portfolio combina una estética clara y personal con elementos retro, superficies suaves y una atención especial a la composición, tipografía y experiencia de usuario.
