# Notas de diseño

Este documento recoge las decisiones principales de identidad visual y experiencia de usuario del portfolio.

## Objetivo

El portfolio debe transmitir personalidad sin perder claridad ni profesionalidad. La interfaz debe destacar por su composición y sistema visual, pero los proyectos y el contenido deben seguir siendo el elemento principal.

## Principios

- Evitar la estética tecnológica oscura con neón demasiado habitual.
- Mantener una identidad propia y reconocible.
- Priorizar jerarquía, legibilidad y espacio visual.
- Utilizar efectos y elementos decorativos con moderación.
- Diseñar los componentes con coherencia entre escritorio y móvil.

## Evolución

Las decisiones visuales se revisarán conforme se integren proyectos reales y se prepare la primera versión pública.
